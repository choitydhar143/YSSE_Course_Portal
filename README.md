# YSSE Course Explorer — revised brand-aligned edition

Built with HTML, CSS and vanilla JavaScript for the Week 5 course search/filter assignment.

## Brand asset
The header/footer use the YSSE logo image hosted at:
https://i.ibb.co/N2GZ2Cvk/logo-png-01.png

The image is a published YSSE organizational logo listing. The official YSSE website is https://ysseglobal.org/. If YSSE provides a downloadable brand-kit logo file, use that file locally instead of the externally hosted image.

## Run
Open the folder in VS Code and launch `index.html` with Live Server. Internet is required for the externally hosted logo, Google Fonts and Unsplash course/hero images.

## Files
- `index.html` — semantic structure, navigation, course directory, contact footer.
- `style.css` — responsive light-green and white brand-aligned design.
- `script.js` — array of course objects, dynamic cards, combined search and filters, sorting, reset, responsive menu.

## Assignment requirements
Eight course objects, dynamic course cards, case-insensitive partial-title search, category filter, difficulty filter, combined filtering, reset, no-results state and responsive grid (4 desktop / 2 tablet / 1 mobile).

## Extra features
Alphabetical sorting, live result count, active-filter summary, mobile menu, footer category shortcuts, keyboard `/` shortcut.

## Data accuracy
Courses are sample entries for the assignment and are not a verified live YSSE catalogue. The footer contact details reflect contact information visible on YSSE's website at the time of preparation; verify before external publication.


Final visual revision: original page structure and JavaScript functionality are preserved; the colour palette has been tuned to YSSE deep green, fresh green and lime accents. The YSSE logo is used as a standalone transparent image, without a square tile or added label.
